# Commande B2B (devis écoles / cliniques / entreprises)

## Process observé
- Prospection ciblée (écoles, cliniques) avec emailing direct via cPanel Roundcube (envoi en BCC groupé)
- Formulaire de demande de devis disponible sur le site WordPress (Contact Form 7)
- Suivi commercial géré en partie via le CRM interne (plugin WordPress `africashopping-crm`) :
  clients, structures, responsables, commandes, factures, export CSV, facturation PDF (mPDF)

## KPI de référence pour une campagne type (cf. exemple du cahier des charges agent IA)
- Nombre de demandes
- Nombre de devis
- Nombre de commandes

*(À compléter : délai de réponse moyen à un devis, conditions de paiement B2B, remises volume)*
